# Changelog

## v1.0.0 — 2026-10-23

First release.

- Apple TV–style home screen for Android TV: full-screen photo wallpaper that blurs when you scroll,
  time, date and live weather in the top-right corner, 5-column app grid using official TV banners.
- Quick buttons: Inputs (HDMI switching), Wi-Fi, Wallpaper, Settings.
- Hold OK on an app: Move, Hide from Home, App info, Show hidden apps.
- System tools and non-TV apps hidden automatically.
- Back never closes the home screen; Home returns to the first app.
- `install.sh` (build + install + set as Home) and `scripts/reset.sh` (undo everything).
- Docs: setup (Java, SDK, adb), debloat, reset, FAQ.
- Tested on a Vu Android TV (Google TV launcher, MediaTek).
